# hitomi_api

hitomi.la 非官方 API 的纯 Dart 实现，协议部分移植自 [node-hitomi](https://github.com/H2Owater425/node-hitomi)（MIT，见 `LICENSE.node-hitomi`）。

用法见 [`example/example.dart`](example/example.dart)，项目整体说明见上级目录的 [README](../README.md)。

```bash
dart test test/hitomi_api_test.dart
```

```bash
dart test --run-skipped -t live test/live_test.dart
```
